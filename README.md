# 🚢 Titanic Survival Analysis

## 📌 Project Overview

This project performs a simple **Titanic Survival Analysis** using Python data analysis and visualization libraries.

The main purpose of this project is to understand how different factors such as **Gender, Passenger Class, and Age** are related to passenger survival.

This project uses a small Titanic dataset created directly in Python and analyzes the data using **Pandas, Matplotlib, and Seaborn**. 📊🐍

---

## 🎯 Project Objectives

The main objectives of this project are:

* 📋 Create and explore a Titanic passenger dataset
* 🔍 Understand the structure of the dataset
* 👩‍🦰👨 Analyze survival rates by gender
* 🎫 Analyze survival rates by passenger class
* 🎂 Study the age distribution of passengers
* 📊 Create attractive data visualizations
* 📈 Understand patterns and relationships in the data

## 📂 Dataset Information

The dataset contains information about **8 Titanic passengers**.

### 📋 Dataset Columns

| Column         | Description                              |
| -------------- | ---------------------------------------- |
| 🆔 PassengerId | Unique ID of the passenger               |
| 🛟 Survived    | Indicates whether the passenger survived |
| 🎫 Pclass      | Passenger class                          |
| 👤 Sex         | Gender of the passenger                  |
| 🎂 Age         | Age of the passenger                     |

### 🟢 Survival Values

* `1` → Passenger survived
* `0` → Passenger did not survive

---

## 📊 Data Analysis

The project performs different types of analysis on the Titanic dataset.

### 👩‍🦰👨 Survival Rate by Gender

The survival rate is calculated separately for male and female passengers.

From the given dataset:

* 👩 Female survival rate: **100%**
* 👨 Male survival rate: **0%**

This small dataset shows a clear difference in survival rates between genders.

---

### 🎫 Survival Rate by Passenger Class

The project also calculates survival rates for each passenger class.

* 🥇 Class 1: **66.67%**
* 🥈 Class 2: **100%**
* 🥉 Class 3: **25%**

This helps us understand how passenger class is related to survival in the sample dataset.

---

## 📈 Visualizations

The project creates **three visualizations**.

### 1️⃣ Survival Rate by Gender 👩‍🦰👨

A bar chart is used to compare the survival rate between male and female passengers.

### 2️⃣ Survival Rate by Passenger Class 🎫

A bar chart displays the survival rate for Class 1, Class 2, and Class 3 passengers.

### 3️⃣ Age Distribution by Survival 🎂

A histogram is used to visualize the age distribution of passengers based on their survival status.
